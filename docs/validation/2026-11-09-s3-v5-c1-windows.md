# S3 提案 V5：C1 窗口统计，S3 满足 δE = 5 kJ/mol，S2 不满足

更新：2026-11-09（Asia/Tokyo）。对应 [C1 合同](../plans/2026-11-01-c1-comparison-contract.md) §4 与 [S3 提案](../plans/2026-11-07-s3-ewald-correction-proposal.md) §4 V5；实验目录 `experiments/2026-11-09_s3_v5_c1_windows/`。用户 2026-11-09 对 V5 计划答"183 跑起来 （跑满"。

**结论：方案 A、PySCF r2SCAN/def2-SVP、C2 扫描的 5 个窗口（各 20 帧）上，相对反应物窗口 w00 的嵌入误差 ΔΔE_emb，S3 为 `+0.02 / +0.09 / +0.10 / +0.07 kJ/mol`（w05 / w06 / w07 / w15，标准误 ≤ 0.01），满足 C1 的 |ΔΔE_emb| ≤ 5 kJ/mol；S2 为 `+4.33 / −12.26 / −8.54 / −14.67 kJ/mol`（标准误 1.7–2.3），在跨越区附近的 w06、w07 和产物样 w15 不满足。**

范围与限制：
- 方法是 PySCF r2SCAN/def2-SVP，不是目标方法 ORCA r2SCAN-3c。ORCA 与 PySCF 的 S3 相对修正量在首批 3 帧上差 ≤ 0.27 kJ/mol（[V2](2026-11-07-s3-v2-orca.md)、V3 Task 5）；ORCA 下的窗口统计未做；2026-11-09 已把修正量的 ORCA/PySCF 桥接扩到这 100 帧，ΔΔC 两程序差 ≤ 0.32 kJ/mol，见 [桥接记录](2026-11-09-s3-orca-bridge-windows.md)。
- 参考 ENV20 是去掉 QM 自身周期镜像的 PySCF 周期 MM 参考（C1 §9 第 4 条）；首批上 ENV30 − ENV20 相对变化 ≤ 0.015 kJ/mol。
- w05–w07 是 xTB 约束扫描中跨越区附近的窗口，不是认证过的过渡态；每窗 0.5 ps、20 个保存帧，16 窗来自同一连续起点，环境历史约 2 ps。
- 本记录只评价嵌入误差；方法误差（M4）、A/C 差异（M3）、TS 认证与自由能不在内。

## 1. 量与统计

`D_X(f) = E_X(f) − E_ENV20(f)`，X = S2、S3，同一几何、同一 S2 点电荷与 QM 设置；S3 另加包内 `EwaldCorrection` 的 50 个赝电荷。`ΔΔE_emb(W) = ⟨D⟩_W − ⟨D⟩_R`，R = w00。窗口内按保存步号排序，用 lag-1 自相关 r1 估有效样本数 `n_eff = n(1 − r1)/(1 + r1)`（r1 < 0 取 0），`SE = SD/√n_eff`，两窗合成 `√(SE_W² + SE_R²)`。帧间隔 25 fs，r1 只描述相邻帧相关，更长程的相关未评价。
