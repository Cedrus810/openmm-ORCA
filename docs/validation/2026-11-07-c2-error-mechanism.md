# C2 首批嵌入误差的来源：S2 缺少的近似均匀场与反应偶极变化

更新：2026-11-07（Asia/Tokyo）。承接 [C2 首批匹配单点](2026-11-07-c2-matched-pilot.md)；实验目录 `experiments/2026-11-07_c2_error_decomp/`。

**结论：首批 3 帧的 S2 误差 `D(f) = E_S2 − E_ENV20` 可由经典势差 `dV = V_Ewald − V_S2` 对 S2 电子密度的一阶作用定量复现：预测的相对变化为 `−10.31 / −15.96 kJ/mol`（3 阶拟合；4 阶 `−10.40 / −16.13`），首批实测 `−10.26 / −16.09 kJ/mol`，差 ≤ 0.15 kJ/mol。** 在 QM 区内 `dV` 近似为常数加均匀场，场差 `|∇dV|` 为 71–86 kJ/mol/nm/e（0.74–0.89 V/nm），三帧方向相近。跨越/产物样帧的相对误差主要来自这一场差与 QM 区偶极变化（Cl 离去）的耦合：偶极项贡献 `+7.40 / +15.10`，常数项（环境构型变化）贡献 `+3.12 / +1.37 kJ/mol`（以 QM 质心为原点）。

适用范围：方案 A、PySCF r2SCAN/def2-SVP、首批 3 个固定构型；经典场差另在 C2 全部 320 帧上计算（§6，无 QM）。未计算 ORCA 密度；未改源码和运行中的 S2 势能。

**320 帧补充（§6）：场差在全部 16 个窗口几乎不变（帧间偏离均值 RMS 13，均值大小 78 kJ/mol/nm/e）；固定 QM 偶极时，场差变化对窗口均值的影响 ≤ 0.6 kJ/mol。环境常数项的窗口均值在 −3.5 到 +5.8 kJ/mol 之间涨落，无随 RC 的趋势。偶极项按 3 帧密度插值估计，随 RC 单调增大到 −9 ～ −17 kJ/mol。在这批构型（同一起点，环境历史约 2 ps）内，窗口平均消不掉这一偏差。**

## 1. 比较的量与方法

- 量：`D(f) = E_S2(f) − E_ENV20(f)`，参考值取首批 PySCF JSON（`D = −48.150 / −58.406 / −64.241 kJ/mol`）。
- 模型：S2 与 ENV 使用同一批点电荷，区别只在外势。`V_S2` 为 S2 请求中最小镜像点电荷的直接库仑和；`V_Ewald` 为同一批电荷的立方盒 Ewald 和，含均匀背景，无 QM 自身镜像，与 ENV 的定义对应。一阶近似 `E_ENV − E_S2 ≈ E1 = Σ_a Z_a dV(R_a) − ∫ n(r) dV(r) dr`，`n` 为 S2 的电子密度；故 `D ≈ −E1 + 常数`。常数为 Ewald 势的约定乘以固定 QM 电荷 −1，在 `D(f) − D(0)` 中抵消；剩余部分为二阶极化等。
- 实现：`decompose.py`。QM 区内 700 个点上精确计算 `dV`，500 个点拟合质心展开的 1–4 阶多项式，200 个点检验；在 DFT 格点上积分。

数值检查：

| 检查 | 结果 |
|---|---|
| 重算 S2 能量与首批之差 | ≤ 4.1e-12 Eh |
| Ewald (α, kmax) = (1.2, 14) 与 (1.6, 20)，去常数后最大差 | ≤ 5.2e-7 kJ/mol/e |
| `dV` 拟合的检验点 RMS（最大）：2 阶 / 3 阶 / 4 阶 | 0.14（0.94）/ 0.010–0.016（0.09）/ 0.002–0.003（0.017）kJ/mol/e |
| 积分域 0.8 nm 内电子数（应为 82） | 81.99998–81.99999；0.8 与 1.0 nm 的 E1 差 < 1e-6 kJ/mol |

0.6 nm 积分域对产物样帧少计约 0.015 个电子，E1 少约 1.1 kJ/mol，所以采用 0.8 nm。

## 3. 场差与 S2 点电荷簇偶极的关系

S2 点电荷簇关于 QM 质心的偶极 `M = Σ q_j (r_j − r_c)` 为 30.7 / 33.3 / 36.2 e·nm。按均匀极化球（立方体同为 1/3 退极化因子）的表面项 `4π·k_e·M / (3V)`：

| 候选 | 表面项 / kJ/mol/nm/e | 与 ∇dV 的夹角余弦 | \|∇dV\| / \|表面项\| |
|---|---|---:|---:|
| 0 | (−25.6, 38.6, −32.0) | −0.984 | 1.26 |
| 4 | (−28.1, 46.4, −28.3) | −0.987 | 1.40 |
| 8 | (−34.2, 45.6, −34.1) | −0.998 | 1.27 |

方向与真空边界簇和 tin-foil Ewald 之间的表面偶极项一致（符号相反、反平行），大小为该均匀极化公式的 1.26–1.40 倍。三帧的 M 方向相近，这一对应还没有在 M 方向不同的帧上检验；大小的差别本文未解释。320 帧中 M 的方向几乎不变（与平均方向的余弦 ≥ 0.965），所以本批数据无法在不同方向的 M 上检验这一对应（§6）。

## 4. 本次确定与未确定的内容

已确定（3 帧、PySCF）：

- 首批 `−10.26 / −16.09 kJ/mol` 是 S2 与周期参考之间外势差的一阶效应；二阶及参考约定合计的帧间变化 ≤ 0.18 kJ/mol。
- 该外势差在 QM 区内以常数和均匀场为主（1 阶拟合残差 RMS 0.6–0.9，2 阶 0.14 kJ/mol/e）。
- 产物样帧的相对误差中，偶极项约占 15.1 kJ/mol，常数项 1.4 kJ/mol；跨越区帧分别为 7.4、3.1 kJ/mol。

未确定：

- 场差在更长时间（M 方向改变）上的分布与均值；本批 320 帧只覆盖约 2 ps 的环境历史（§6）。B5 的反应物区力偏移是否由同一场差解释（未逐帧计算）。
- ORCA r2SCAN-3c 密度下的同一分解。`dV` 是经典量，与 QM 程序无关；偶极随反应的变化需用 ORCA 密度核实。
- 1.26–1.40 倍的来源。

## 未确认（Claude 推断）

以下为推断，未经计算或用户确认，不作为正文结论：

- 表面项由整个盒的极化决定，水的介电弛豫约为几 ps。§6 已表明在本批构型内窗口平均消不掉；更长采样下 M 的均值是否趋于零、会不会让平均偏差变小，属推断，未计算。蛋白有固有偶极，M 的均值不一定为零。
- 偶极项的量级约为 `|∇dV| × |Δμ|`；反应中 Cl 离去引起的 Δμ 约 0.3 e·nm 时，场差 70–85 kJ/mol/nm/e 即对应约 15 kJ/mol。要满足 5 kJ/mol，场差须降到约 1/3。
- 每步给 S2 加入经典计算的 `dV`（常数 + 均匀场，或多项式）可以消去大部分误差，计算量为一次经典 Ewald；这就是 Ewald 修正嵌入（S3），属于设计稿 §1.2 和 C1 §8 的非目标，是否改变范围由用户决定；方案见 [S3 提案](../plans/2026-11-07-s3-ewald-correction-proposal.md)。
- B5 的伸缩/进攻力恒定偏移（+36.8 / −53.0 kJ/mol/nm）可能就是该均匀场作用在 QM 区电荷上的力。

## 6. 320 帧的经典场差统计

`field_stats.py` 用首批相同的零力捕获后端，从 `createMixedSystem` 取出 C2 扫描全部 16 窗 × 20 帧的 S2 请求，每帧在 QM 区内 325 个点上精确计算 `dV`，3 阶拟合（检验点 RMS ≤ 0.025、最大 ≤ 0.14 kJ/mol/e），记录质心处常数 c0、梯度 g 和 S2 簇偶极 M。不做 QM。181 本机，8 进程 × 2 窗，约 90 s。`analyze_fields.py` 汇总为 `field_stats.json`。

读法：

- 单极项是环境噪声：帧间 SD 约 5 kJ/mol（与 B5 反应物区的 4.5 同量级），窗口均值在 −3.5 到 +5.8 之间，无随 RC 的趋势。

- 局限：16 窗的环境来自同一起点（串行 pull 每窗 200 步，再各跑 1400 步），环境历史约 2 ps，M 方向几乎不变。更长时间 M 改变方向后的平均行为，本批数据回答不了。偶极项依赖插值的 μ，每帧的 QM 密度未计算。
