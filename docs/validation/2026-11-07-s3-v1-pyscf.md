# S3 提案 V1：PySCF 原型把首批相对嵌入误差降到 0.12 kJ/mol 以内

更新：2026-11-07（Asia/Tokyo）。对应 [S3 提案](../plans/2026-11-07-s3-ewald-correction-proposal.md) §4 V1；实验目录 `experiments/2026-11-07_s3_v1_pyscf/`。用户 2026-11-07 对"要我跑 V1 吗？"答"可以"。

**结论：在首批 3 帧（方案 A，PySCF r2SCAN/def2-SVP）上，把经典 Ewald 修正势加进 SCF 后，相对候选 0 的 `E − E_ENV20` 变化从 S2 的 `−10.26 / −16.09` 降到：2 阶多项式 `+0.11 / +0.02`，3 阶 `−0.0002 / +0.005`，正则化赝电荷（2 阶，K = 50）`+0.02 / +0.03 kJ/mol`。只做 1 阶为 `+0.04 / +0.43`。** 赝电荷不加正则时电荷可达 256 e，加岭回归后 ≤ 0.62 e，能量结果相当。

范围：3 个固定构型、单程序、只比较能量。未做 ORCA（V2）、力与有限差分（V3）、窗口统计（V5）；未改 `openmmorca/`。

## 1. 比较的量

`R_v(f) = E_v(f) − E_ENV20(f)`，同一 QM 几何、方法、基组和 S2 点电荷；ENV20 为首批的 PySCF 周期 MM 参考（去掉 QM 自身镜像）。S2 行即首批的 `D(f)`。相对量 `R_v(f) − R_v(0)` 是 C1 的嵌入误差定义在单构型上的形式；目标 δE = 5 kJ/mol（用户 2026-11-01）。

变体（`dV` 由 `classical.py` 在 QM 区 700 个点上精确计算，500 点拟合、200 点检验）：

- S3_o1 / o2 / o3：1/2/3 阶多项式势直接加入 SCF（电子：多项式的单电子积分；核：常数项）。
- S3_P2：2 阶多项式由离 QM 质心 R_s 处 Fibonacci 球面上的 K 个点电荷拟合表示，追加到 S2 点电荷，即提案 §3.1 的方案 P。两组：K = 100、R_s = 2.0 nm、无正则；K = 50、R_s = 2.0 nm、岭回归 λ = 1e-4。

## 2. 结果（kJ/mol）

| 变体 | R(0) | R(4) | R(8) | 相对 R(4) − R(0) | 相对 R(8) − R(0) |
|---|---:|---:|---:|---:|---:|
| S2（首批） | −48.1504 | −58.4063 | −64.2412 | −10.2559 | −16.0908 |
| S3_o1 | 1.0393 | 1.0760 | 1.4717 | +0.0367 | +0.4324 |
| S3_o2 | 0.7738 | 0.8880 | 0.7925 | +0.1142 | +0.0187 |
| S3_o3 | 0.8828 | 0.8827 | 0.8880 | −0.0002 | +0.0052 |
| S3_P2（K 100，无正则） | 1.1758 | 1.2027 | 1.2430 | +0.0269 | +0.0672 |
| S3_P2（K 50，λ 1e-4） | 1.1645 | 1.1879 | 1.1978 | +0.0234 | +0.0333 |

- 绝对值约 0.8–1.2 kJ/mol 的偏移在三帧间基本相同，属于我的 Ewald 势常数约定与 PySCF 约定之差乘以 QM 电荷 −1（误差来源记录中 `D + E1` 也约为 1.0），在相对量中抵消。
- 对照尺度：首批参考自检 ENV30 − ENV20 的相对变化为 0.013 / 0.009 kJ/mol。3 阶修正后的相对残差（≤ 0.005）低于该自检量级；2 阶为 0.02–0.11。
- 重算的 S2 能量与首批之差 ≤ 4.1e-12 Eh。`dV` 拟合检验点 RMS：1 阶 0.58–0.81，2 阶 0.11–0.17，3 阶 0.008–0.014 kJ/mol/e。

## 3. 赝电荷的条件数

`pseudo_conditioning.py`（纯经典）扫描 K = 20/50/100、R_s = 1.5/2.0/3.0 nm、λ = 0/1e-4/1e-2：

- 不加正则时，K 越多、R_s 越大，最小二乘越病态：候选 0 在 K = 100、R_s = 2.0 时 |Q| 最大 201 e（SCF 用的那组拟合点上为 256 e），R_s = 3.0 时 1.3e4 e；拟合误差几乎不变。
- 岭回归 λ = 1e-4 后，三帧、K = 50/100、三种 R_s 的 |Q| 最大值在 0.19–0.71 e 之间，对 2 阶多项式的拟合 RMS 0.06–0.09 kJ/mol/e，与不加正则相差 ≤ 0.019。SCF 中 K = 50 的一组 |Q| 最大 0.30–0.62 e，赝电荷总电荷 −0.70 ～ −0.75 e。
- 赝电荷只能产生调和势；`dV` 的二次项有非零迹（拟合得到的拉普拉斯 5.2–7.1 kJ/mol/e/nm²，来自 Ewald 的均匀背景），这部分表示不了，对应残差约 0.06–0.10 kJ/mol/e。对相对能量的影响在上表 P2 行中已包含（≤ 0.07）。

## 4. 结论与下一步

已确定（本 3 帧、PySCF、能量）：

- S3 的定义在能量上重现了 ENV 参考的相对能量：2 阶修正把相对误差从 10–16 kJ/mol 降到 ≤ 0.12 kJ/mol，3 阶 ≤ 0.005 kJ/mol。
- 只做 1 阶时，产物样帧残差 0.43 kJ/mol；2 阶是提案中建议的阶数，本批数据支持该选择。
- 方案 P（赝电荷）可用，但必须正则化；正则化后能量残差 ≤ 0.03 kJ/mol。

未确定：

- ORCA r2SCAN-3c 路径（V2）；力的链式回分与有限差分（V3）；B5 反应物区力偏移是否消失（V4）；窗口统计（V5）。
- 方案 P 的 MM 力需要 QM 多极矩，是否从 ORCA 输出读取或由 pcgrad 反推，尚未选定（提案 §3.2）。
