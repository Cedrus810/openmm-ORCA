## E1 结果

伸缩力 = 0.5 u·(F_C1 − F_Cl1)，u 从 Cl1 指向 C1，正值表示把 C1–Cl1 拉长；进攻力 = 0.5 v·(F_C1 − F_O)，v 从 O 指向 C1，O 取离 C1 较近的那个 Asp124 氧，正值表示把 O、C1 推开。力的单位 kJ/mol/nm，能量 kJ/mol。

|---|---|---|---|---|---|
| S2 − EW20 | 20 | 41.0 / 114.5 | +36.8 / 38.7 | −53.0 / 54.3 | 4.53 |

- 参考本身：`rcut_hcore` 从 20 Å 换到 30 Å，QM 力最多变化 0.7 kJ/mol/nm，比 S2 的误差小两个数量级。
- 桥接（E1c）：S0 − S2 的伸缩力差，ORCA r2SCAN-3c 与 PySCF r2SCAN/def2-SVP 逐帧相关 1.000，斜率 ORCA/PySCF = 1.035，残差 RMS 3.4；能量差的帧间标准差分别是 83.36 和 83.38，两者之差的标准差 0.47。所以在这 20 帧上，嵌入方式造成的伸缩力和能量变化，在两个程序、两种方法之间可以互相换算。进攻力没有做桥接（ORCA 侧缺少对应的比较），这一项只有 PySCF 的值。
- 每帧耗时（183 与 180 混合的平均）：S0 44 s，S2 53 s，EW20 97 s。

### E1 结论（方案 A，T09 的 20 帧，都在反应物区）

1. S2 相对周期 Ewald 的剩余误差有了直接测量：伸缩力 +36.8 kJ/mol/nm（RMS 38.7），与 B4 按线性响应外推的约 +38.7 一致；能量帧间标准差 4.5 kJ/mol，与 B4 经典估计的 4.1–4.3 一致。按桥接斜率换算到 ORCA，伸缩力约 +38。
2. 新发现：S2 对 O–C1 进攻力也有偏差，−53.0 kJ/mol/nm（RMS 54.3），比伸缩力的偏差还大。两项都几乎是恒定偏移：平均值接近 RMS，伸缩力的帧间标准差约 12，进攻力约 12。
3. 对势垒的影响（推算，前提是这个偏差在 TS 附近仍然是同一个常数，而这一点没有验证）：S2 的能量减去 Ewald 的能量，在从反应物走到 TS 的过程中，变化约为 −(36.8·Δd_CCl + 53.0·|Δd_OC|)。其中 Δd_CCl > 0 是 C1–Cl1 的伸长量，|Δd_OC| 是 O–C1 的缩短量，单位 nm。两项都会让 S2 **低估**势垒：两个距离各变化 0.1 nm，约低估 9 kJ/mol。TS 处这两个距离各变化多少，要等阶段 C 给出构型。

- ORCA 每个单点：A 约 8.9 s（np18）；C 在 181 上约 63 s（np18），在 180 上约 111 s（np4）。
- 与 B3-1（S0 型的同一嵌入集合 S_C，T09 帧）比较：伸缩力 Δ RMS 25.5、能量差帧间标准差 17.0；这次在 S2 下分别是 25–28 和 18–19，结论没有变。

### E2 结论

1. 嵌入固定为 S2 之后，把 QM 区从 A 扩大到 C：反应坐标上的力变化 RMS 约 25–35 kJ/mol/nm（伸缩力和进攻力），相对能量的帧间标准差约 18–19 kJ/mol；接触原子（Cl1、OD1、CG）的局部力变化大，可达 400 kJ/mol/nm 左右。两组帧（A 的轨迹和 C 的轨迹）结论一致。
2. 这个量级和 S2 自身的剩余误差（伸缩 37、进攻 53 kJ/mol/nm）相当。所以在反应物区，"QM 区 A 还是 C"和"S2 还是周期 Ewald"对反应坐标力的影响大小相近。不同的是：嵌入误差几乎是常数，QM 区的差异则逐帧变化（RMS 明显大于平均）。
3. 能量方面：QM 区的差异（帧间标准差 18–19）大于 S2 的嵌入误差（4.5）。

## 按 δE = 5 kJ/mol 的推算（2026-11-01）

用户 2026-11-01 原话："δE = 5 kJ/mol，作为嵌入对势垒或反应能的误差上限。 这是阶段 C 的验收目标，不是从已有误差反推一个能让 S2 通过的数"。

下面只是把 δE 代进 E1 结论第 3 条的式子，前提同样是"偏差在 TS 附近仍为同一个常数"，这一点没有验证：

- 条件：36.8·Δd_CCl + 53.0·|Δd_OC| ≤ 5 kJ/mol（PySCF 值；伸缩项按桥接斜率 1.035 换算到 ORCA 后约为 38.1）。
- 只有 C1–Cl1 伸长时，Δd_CCl ≤ 0.136 nm；只有 O–C1 缩短时，|Δd_OC| ≤ 0.094 nm；两者变化相同时，各自 ≤ 0.056 nm。
- 反应物区的帧里，O–C1 是 0.24–0.33 nm，C1–Cl1 约 0.177 nm（最大 0.207）。TS 处这两个距离是多少，本项目没有数据。所以 S2 在 δE 下"可用 / 不可用"，现在给不出结论，属于"未评价：缺 TS 附近构型及该处的 S2 − Ewald 偏差"。
- δE 只约束嵌入误差。E2 中方案 A/C 的差异（相对能量帧间标准差 18–19 kJ/mol）是 QM 区的影响，不属于嵌入误差，不拿 δE 去判断它。
