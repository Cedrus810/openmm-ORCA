# 路线 B3：方案 C 与方案 A 的对照（2026-10-16）

对应 [项目路线](../plans/2026-10-15-project-roadmap.md) 阶段 B3。B3-1：匹配快照上的单点；B3-2：方案 C 短跑 500 步。

## 设置

- 方案：A = DCE + Asp124 侧链（14 个 QM 原子 + 1 个 link H）；C = A 再加 Trp125、Trp175、His289（HID）侧链（61 个 QM 原子 + 4 个 link H，边界 1975–1971、1987–1983、2742–2738、4512–4508）。两者都是电荷 −1、多重度 1；r2SCAN-3c，cutoff 1.2 nm。方案 C 没有出现 QM 电荷与力场不一致的警告。
- 快照：T09 的 20 帧，取自 2026-10-05 方案 A 的轨迹（第 100–2000 步，每 100 步一帧）。
- 三组单点，几何完全相同：

  | 记号 | QM 区 | 嵌入集合 | 来源 |
  |---|---|---|---|
  | A(S_A) | A | A 自己的 1.2 nm 选组（平均约 155 组） | T09 `scan/c1.200.npz`（183，np16） |
  | A(S_C) | A | C 的 1.2 nm 选组所含的全部残基（平均约 320 组，按 A 的分组） | B3-1b，`sp_a_setC/` |
  | C(S_C) | C | C 自己的 1.2 nm 选组 | B3-1a，`sp_c/` |

  A(S_A) → A(S_C) 只改变嵌入集合，A(S_C) → C(S_C) 只改变 QM 区。B3-1b 用 B2 的集合覆盖脚本 `b2_singlepoints.py`，`--reach 2.6`：C 选中的组离方案 A 最远超过 2.0 nm；上限由 reach + A 的尺寸（0.742 nm）< 半盒宽（3.409 nm）决定。第一次用 2.7 时被盒宽检查拦下，没有产生结果。
- 只比较总力和总能量（MM + QM）：方案 C 把 DCE/Asp124 与 Trp/His 之间的作用（静电和 LJ）从 MM 移进了 QM，只看 QM 力组不可比。MM 部分用各自混合 System 中除 QM 力组以外的全部力组，在 CPU 平台上计算（不调 ORCA）。
- 比较对象：两个方案共有的 14 个 QM 原子。不同 QM 区的绝对总能量不比较，只看能量差的帧间标准差。
- 产物：`experiments/2026-10-16_b3_region_c/`，包括 `run_sp_c.sh`、`b3_jobs_a_setC.py`、`run_sp_a_setC.sh`、`b3_analyze_sp.py`（输出 `b3_analyze_sp.log`、`b3_sp_results.json`）、`b3_setC_charge.py`（输出 `b3_setC_charge.log`）。
- 耗时（181，两个进程各 np18）：C 单点 65–71 s；A(S_C) 单点约 7 s。冒烟时 C 单点在 np18 下 42–48 s、np36 下 33–36 s。正式运行比冒烟慢，原因没有查。

## 一致性检查

- `b3_jobs_a_setC.py` 重算的 C 选组数，与冒烟中 ORCA 侧记录的组数一致（第 0、1 帧分别是 322、315）。按 A 的分组取同一批残基后，组数与 C 的选组数逐帧相同。
- A(S_A) 是 A(S_C) 的子集，20 帧都成立（脚本中有 assert）。

## 结论（只在本数据范围内：20 帧取自方案 A 的轨迹，r2SCAN-3c，cutoff 1.2 nm）

1. **按各自的 1.2 nm 选组比较时（这也是实际运行时的情形），A 和 C 的差别主要来自嵌入集合，而不是 QM 区。** 只换嵌入集合时，C1–Cl1 伸缩力平均偏移 −254 kJ/mol/nm，能量差的帧间标准差为 90 kJ/mol；只换 QM 区时，分别是 +12 kJ/mol/nm 和 17 kJ/mol。这和 B1/B2 的结论一致：C 的选组球更大，多纳入了约 −4 e 的远处带电组，它们的电场使反应键极化。所以在硬截断下，"方案 C 比方案 A 好多少"无法与截断伪影分开。
2. **嵌入集合相同时，换 QM 区对反应键伸缩和帧间能量的影响小，但对接触原子的力影响大。** 伸缩 Δ RMS 为 25.5，能量差帧间标准差为 17 kJ/mol（能量相关 0.999）。但 Cl1（334）、OD1（287）、CG（207）、H22（102）的总力差很大，14 原子合力的差 RMS 达到 375。Cl1 位于 Trp125/Trp175 的卤素结合位点（prep §5）。OD1、CG、H22 各自接触 C 中哪个侧链，本次没有核对几何；按 prep §5，2DHC 中对着 His289 的是 OD2，而这里差别大的是 OD1，所以不能直接归到 His289 上。推测（未核实）：把这些接触从 MM（固定电荷 + LJ）换成 QM，主要改变的是局部的接触力。这是 QM 和 MM 对同一作用的描述不同，与截断无关；哪一种更接近参考值，本次没有判断。
3. **对后续的含义（推论，未验证）：** QM 区的比较要在嵌入方案确定之后（B4），或者在固定的同一嵌入集合下进行；否则截断伪影会掩盖 QM 区本身的影响。

## B3-2：方案 C 短跑（500 步完成）

- 183，np36 + CUDA，500 步（0.25 ps），`run_md_c.sh`，输出 `md_c/`；可以用 `--resume checkpoint` 续跑，也可以用 `--steps N` 延长。
- 起始状态与 2026-10-05 的方案 A 运行相同：复制了那次的 `prepared.pdb` 和 `equilibrated.xml`，冒烟时确认 MM 平衡缓存被复用。两次运行的第 1 步温度分别为 296.65 K（C）和 296.74 K（A）。
- 冒烟（3 步，`md_c_smoke/`）：第 1 步 36–39 s（SCF 从头开始），之后 25 s/步。
- 2026-10-16 12:38–16:42 运行，墙钟 14,647 s，平均 29.1 s/步（t_orca 29.06 s，p95 30.85 s），没有 fresh retry。smoke checks PASS；Task 22 验收要求 2000 步，所以标为 NOT_EVALUATED。

- 只有一条 0.25 ps 的轨迹。两次运行在第 1 步之后就因 QM 力不同而分开，所以 O–C1、C1–Cl1 的差别只描述这两条轨迹，不能当作两个方案的统计差异。
