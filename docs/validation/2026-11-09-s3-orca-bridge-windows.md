# S3：ORCA r2SCAN-3c 与 PySCF 的修正量在 V5 窗口上一致到 0.32 kJ/mol

更新：2026-11-09（Asia/Tokyo）。承接 [V5 窗口统计](2026-11-09-s3-v5-c1-windows.md)，把 [V2](2026-11-07-s3-v2-orca.md) 的 3 帧桥接扩到 V5 的 100 帧；实验目录 `experiments/2026-11-09_s3_orca_bridge_windows/`。用户 2026-11-09 对计划答"跑起来"，并要求"183 有东西注意规避"。

**结论：同一几何、同一组 S2 点电荷与赝电荷下，S3 修正量 `C = E_S3 − E_S2` 相对 w00 的窗口变化 ΔΔC，ORCA r2SCAN-3c 与 PySCF r2SCAN/def2-SVP 之差为 `+0.07 / +0.32 / +0.18 / +0.11 kJ/mol`（w05 / w06 / w07 / w15，标准误 ≤ 0.12），而 ΔΔC 本身为 −4.2 ～ +14.9 kJ/mol。** 两个程序的 QM 密度对修正势的响应在这些窗口上相同到约 2%。

范围：ORCA 没有周期参考，本记录**没有**直接计算 ORCA 下的嵌入误差。

## 1. 量

`C(f) = E_S3(f) − E_S2(f)`，各程序在自身方法下计算；PySCF 一侧取 V5 的能量。`ΔΔC(W) = ⟨C⟩_W − ⟨C⟩_w00`；两程序之差逐帧配对后再做窗口统计。统计方法（lag-1 自相关估有效样本数）同 V5。

- 冒烟核对：w00 第 0 帧 ORCA S2 与首批候选 0、S3 与 V3 Task 5（API 路径）的能量差均为 0.0 kJ/mol。
- PySCF 的 ΔΔC 与 V5 中 S2 的 ΔΔE_emb 符号相反、大小相近（w06 +12.35 对 −12.26），即 S3 修正量抵消了 S2 的窗口误差，与 V5 一致。
- 首批 3 帧上 V2/Task 5 的差（+0.27 / −0.04）与此处同量级。

## 3. 推断（未直接验证）

ORCA 下 S3 的窗口误差 = ORCA 下 S2 的窗口误差 + ORCA 的 ΔΔC。PySCF 中这两项互相抵消到 ≤ 0.10 kJ/mol（V5），且误差来源记录表明 S2 误差几乎全部是外势差的一阶作用。若 ORCA 中 S2 误差同样由一阶作用主导，则 ORCA 的 S2 误差与 ΔΔC 也应抵消，ORCA 下 S3 的 |ΔΔE_emb| 估计在 0.1 + 0.3 kJ/mol 的量级，远小于 δE = 5。这一步依赖"ORCA 中一阶作用同样主导"，没有周期参考可以直接核对。
