# S3 提案 V4：S3 消除了 B5 反应物区的恒定力偏移

更新：2026-11-09（Asia/Tokyo）。对应 [S3 提案](../plans/2026-11-07-s3-ewald-correction-proposal.md) §4 V4；实验目录 `experiments/2026-11-09_s3_v4_b5_forces/`。用户 2026-11-09 对 V4 计划答"跑"，对冒烟后加的 S3 差分检查答"可以"，对改为全差分方案答"可以"。

**结论：在 B5 的 20 个反应物区帧上（方案 A，PySCF r2SCAN/def2-SVP），相对去掉 QM 自身镜像的周期参考 ENV20，S2 的伸缩/进攻力偏移为 `+36.68 / −53.00` kJ/mol/nm（帧间 SD 12.0 / 12.1），S3 为 `−0.48 / +0.13`（SD 0.12 / 0.09）；能量差的帧间 SD 由 S2 的 4.53 降到 S3 的 0.014 kJ/mol。** 三者的力投影都由同一种能量方向差分得到。

范围：反应物区 20 帧，单程序（PySCF），力只看伸缩、进攻两个投影。ORCA 下的同一比较、跨越区/产物区的力未做。

## 1. 量与方法

- 伸缩力 = 0.5 u·(F_C1 − F_Cl1)，进攻力 = 0.5 v·(F_C1 − F_O)，定义与 [B5](2026-10-29-b5-scope.md) 相同。
- 投影力由能量方向差分得到：C1 与 Cl1（或 O）沿 u（或 v）相向各移 ±λ/2，λ = 0.002 Å，力 = −(E₊ − E₋)/(2λ)。SCF conv_tol 1e-10 Eh，差分噪声约 1e-3 kJ/mol/nm。
- 参考 ENV20：首批 `periodic_reference.py` 的周期 MM 场，去掉 QM 自身镜像；其解析梯度未验证，所以只用差分。S3 赝电荷由包内 `EwaldCorrection` 生成（|Q| ≤ 0.18 e）。

## 2. 冒烟发现：解析梯度与能量差分有共同的系统差

第 0 帧对照：EW20 的差分与 B5 的 EW20 解析梯度在伸缩投影差 −16.71、进攻差 −0.15 kJ/mol/nm；S3（分子嵌入路径）的差分与其解析梯度差 −16.71 / −0.15，几乎相同。全部 20 帧：S2 与 S3 的"差分 − 解析"伸缩投影均为 −13.2 ± 2.3（范围 −17.2 ～ −7.1），进攻 +0.3 ± 0.9，两者逐帧之差最大 0.06（伸缩）/ 0.08（进攻）。

所以这是 PySCF r2SCAN 解析梯度相对于能量的共同偏差，与嵌入方式无关；同一种方法内部相减时抵消。原因推测为 PySCF DFT 梯度默认不含积分格点随原子移动的贡献（r2SCAN 对格点敏感），**未核实**。本记录的结论只用同法相减的结果，不用"解析减差分"的混合差。

## 3. 结果（20 帧，kJ/mol/nm；能量 kJ/mol）

| 比较 | 伸缩 平均 / RMS / SD | 进攻 平均 / RMS / SD | 能量差帧间 SD |
|---|---|---|---:|
| 差分：S2 − ENV20 | +36.68 / 38.58 / 11.97 | −53.00 / 54.37 / 12.14 | 4.534 |
| 差分：S3 − ENV20 | −0.48 / 0.49 / 0.12 | +0.13 / 0.16 / 0.09 | 0.014 |
| 解析：S2 − EW20（B5） | +36.80 / 38.69 / 11.97 | −52.97 / 54.34 / 12.14 | 4.534 |
| 解析：S3 − EW20 | −0.36 / 0.37 / 0.11 | +0.15 / 0.18 / 0.10 | 0.014 |
| 解析：S2 − S3 | +37.15 / 39.06 / 12.05 | −53.12 / 54.50 / 12.18 | 4.537 |
| 差分：S2 − S3 | +37.16 / 39.07 / 12.06 | −53.13 / 54.51 / 12.18 | 4.537 |

- B5 的 `+36.8 / −53.0` 在差分下重现（+36.68 / −53.00），说明 B5 的解析对解析结果不受第 2 节偏差影响；EW20 与 ENV20（是否含 QM 自身镜像）对这两个投影的影响在第 0 帧为 −0.18 / +0.03。
- S3 剩余偏移 −0.48 / +0.13 kJ/mol/nm，约为 S2 偏移的 1% 和 0.3%；按 B5 的推算方式（偏移 × 0.1 nm 位移），对应能量量级 ≤ 0.05 kJ/mol。
- 第 0 帧重算 S2 与 B5 一致：能量差 2.7e-12 Eh，梯度差 3.9e-13 Eh/bohr。
