# S3 提案 V2：ORCA 中的 S3 修正量与 PySCF 一致到 0.26 kJ/mol

更新：2026-11-07（Asia/Tokyo）。对应 [S3 提案](../plans/2026-11-07-s3-ewald-correction-proposal.md) §4 V2；实验目录 `experiments/2026-11-07_s3_v2_orca/`。用户 2026-11-07 对"要我跑 V2 吗？"答"跑"。

**结论：ORCA r2SCAN-3c 接受追加到 `%pointcharges` 的 50 个赝电荷，SCF 正常。相同输入下，S3 修正量 `E_S3P2 − E_S2` 相对候选 0 的变化，ORCA 为 `+10.54 / +16.08`，PySCF r2SCAN/def2-SVP（V1）为 `+10.28 / +16.12 kJ/mol`，差 `+0.26 / −0.04 kJ/mol`。** 修正量的绝对值两程序差 0.18–0.49 kJ/mol。

范围：3 个固定构型、能量。ORCA 没有直接的周期参考；ORCA 下 S3 相对周期参考的残差只能经桥接推断（§3）。未做力和有限差分（V3）；未改 `openmmorca/`。

## 1. 比较的量

两个程序各自在相同 QM 几何、相同 S2 点电荷、相同赝电荷下算 `C(f) = E_S3P2(f) − E_S2(f)`，再取 `C(f) − C(0)`。这是 S3 对相对能量的修正量；V1 已表明在 PySCF 中，该修正把相对误差从 `−10.26 / −16.09` 降到 `+0.02 / +0.03 kJ/mol`。

赝电荷：V1 中 K = 50、R_s = 2.0 nm、λ = 1e-4 的一组，`make_pseudo.py` 重新生成，与 V1 记录的 |Q| 最大值（0.51 / 0.30 / 0.62 e）和总电荷逐位相同。

## 3. 解释

已确定：

- ORCA 路径可直接使用方案 P（赝电荷追加到点电荷文件），不需要改 backend 或 ORCA 文件读写。
- 两程序在同一输入上给出的 S3 相对修正量相差 ≤ 0.26 kJ/mol。

推断（未直接计算）：首批桥接中 ORCA 与 PySCF 的 `S0 − S2` 相对变化差 1.0–1.6 kJ/mol，说明两种方法的密度对外场的响应接近。若 ORCA 下 S2 的相对嵌入误差与 PySCF 的差别也在同一量级，则 ORCA S3 相对周期参考的残差约为 V1 残差（≤ 0.03）加上修正量之差（≤ 0.26），远小于 δE = 5 kJ/mol。ORCA 没有周期参考，这一点无法直接核对。
