# ONIOM 双层减法方案实施计划（v0.2.1）

日期：2026-09-28。前置：M0–M3 已验收（v0.2.0，full-QM / QM/MM 电子嵌入 / restart / 诊断）。

## 动机

QM/MM（电子嵌入）已覆盖"QM 区 + MM 环境"的场景；ONIOM 补上**多层 QM**：当整个体系对高精度方法太大、但对某个廉价 QM 方法（xTB、HF/小基组、复合方法）还放得下时，用

```text
E_ONIOM = E_high(model) + E_low(full) − E_low(model)
F(model 原子)   = F_high(model) + F_low(full) − F_low(model)
F(其余原子)     = F_low(full)
```

其中 model 区用高水平算、全体系只用一次低水平算。基础设施（backend 协议、`QMRequest/QMResult`、力散射、restart 链、失败包）全部复用，因此"不远"。

## 物理与约束

- **层间机械耦合**（标准 Morokuma ONIOM）：减法交叉项相消要求两层 QM 之间**不加点电荷嵌入**——给 model 区嵌入外层电荷会改变方案本身（那是加法 QM/QM' 的领域），本版不做。
- **model 区必须整分子**（无 link atom），复用 `qmmm.system.check_whole_molecules`。
- 所有粒子都是真实原子（无虚拟位点），System 是纯粒子容器：质量 + PythonForce，**不含力场**——能量完全来自 ONIOM 组合。
- **电荷契约**：`high` 的 charge/multiplicity = model 区的值；`low` 的 = 全体系的值。低层 model 区计算（E_low(model)）用 low 的方法/选项、但取 **model 区的 charge/multiplicity（即 high 的值）**——与 Gaussian ONIOM 的 model-low 默认一致；因此 low-only 原子可以带电或开壳层（2026-09-29 修正：初版让 low_model 沿用全体系电荷，low-only 区带电时会静默算错或被电子数校验拒绝）。
- 每步 **3 次 QM 调用**（1 高 2 低），这是 ONIOM 的固有开销。

## 实现要点

- 新模块 `openmmorca/oniom.py`：`ONIOMCallback`（State → 3 个 `QMRequest` → 减法组合）+ `ONIOMPotential`（组合两个 `ORCAPotential`，全部 ORCA 选项/参数沿用）。
- **每个 System 创建 3 个独立 backend**：high、low_full、low_model。full 与 model 的 low 层计算绝不能共用 backend——`restart/last_good.gbw`（MORead 初猜）的尺寸必须与各自原子数匹配，共用了会每步白白烧一次失败 SCF。
- `ONIOMCallback` 返回的力是 E_ONIOM 的精确梯度（fake 后端有限差分验证）；三个结果各自动量守恒，组合亦然。
- 公共辅助下沉：`qmmm.system.validate_atom_indices`（原 `build_mixed_system` 内联校验）、`potential.topology_masses`（原 `createSystem` 内联逻辑）、`make_python_force(name=...)`。
- API：`ONIOMPotential(high=..., low=...).createONIOMSystem(topology, atoms, removeCMMotion=True, forceGroup=0)`；`summarize_timings()` 汇总两层全部 backend；`close()` 委托两层。

## NVE 实测（2026-09-29，v0.2.2）

`examples/oniom_water_cluster.py`：5 水团簇，model = 水 0，HF/STO-3G TightSCF : GFN2-xTB，力场预极小化，0.25 fs，300 K 初速度（去质心平动），每 10 步采样，Reference 平台，串行 ORCA（`taskset` 16 核，两组并发跑）。

| 时长 | 步数 | 总能量漂移 | 总能量标准差 | max\|E−E₀\| | 同期势能起伏 | 每步耗时 |
|---|---|---|---|---|---|---|
| 0.1 ps（脚本默认） | 400 | +0.0355 kJ/mol/ps | 0.0276 kJ/mol | 0.080 kJ/mol | 35.3 kJ/mol | 938 ms |
| **1 ps** | 4000 | **+0.0067 kJ/mol/ps** | **0.0231 kJ/mol** | 0.093 kJ/mol | 39.2 kJ/mol | 732 ms |

- 1 ps 结果落在 QM/MM 的 v0.1 验收阈值内（spec §1.3：漂移 < 0.017 kJ/mol/ps、标准差 < 0.05 kJ/mol；QM/MM 实测 +0.0056、0.0163），与 QM/MM 同一量级。0.1 ps 只有 41 个采样点，漂移斜率不可靠，以 1 ps 为准。
- 每步耗时 ≈ 三次调用之和（1 ps 组：high 0.38 s + low_full 0.15 s + low_model 0.14 s，均值，冷启动已剔除）；三次调用互相独立，并发执行可把每步压到约 max(·) ≈ 0.4–0.5 s（未实施）。

## 版本

ONIOM 发布为 **v0.2.1**（v0.2 的功能补充）；原计划版本号不变：M4 link atom = v0.3，M5 周期性 MM + 截断嵌入 = v0.4。

**v0.2.2**（2026-09-29）：修正 E_low(model) 的电荷/多重度——低层 model 区计算改用 model 区（`high`）的 charge/multiplicity，取消"low-only 原子净电荷必须为 0"的限制；这是行为变更（low-only 区带电时 v0.2.1 会静默算错或被电子数校验拒绝），故单独升补丁版本。同版附带：无键 topology 警告、`summarize_timings` 同一对象去重、restart 链测试加强。

## 已知限制与后续

- 只有两层（high:low）；N 层（QM:QM:QM…）与 QM:MM 层类型（机械嵌入 QM/MM，需双 Context 算 E_MM(full) − E_MM(model)）留待后续。
- 层间机械耦合：不带嵌入。
- model 区整分子校验依赖 topology 的键；topology 完全无键时发 `UserWarning`（无法检测切断分子）。
- `createONIOMSystem` 不接受输入 System（无力场可改造），粒子/质量全部来自 topology。
